# 真正要回答的问题

围绕这家公司，具体回答：**公司实际经营的产品或服务与新闻所指产业链是否真的有关；若有关，属于直接业务、宽口径分部中的一部分还是尚未形成收入的产品布局；事件将通过什么路径影响收入和利润；若无关，具体错位在哪里。**

不要先寻找一句概括性的“核心矛盾”，直接进入公司产品、收入分部和事件传导的具体分析。

# 业务语义判断原则

主营业务分部是会计口径，不是关键词标签。必须理解名称所代表的实际业务，不能只比较文字是否相同：

- 名称不同但业务相同，应识别为相关。例如“光电子及半导体封测设备”可以包含CPO耦合、封装和测试设备；
- 名称宽泛且可能包含相关产品，应写明“宽口径包含”，但不得把整个分部占比都当作事件敞口。例如“3C电子产品”可能包含服务器、交换机或通信硬件；
- 公司已有明确的相关产品，但收入没有独立分部时，应确认业务联系成立，同时说明具体权重无法量化，不能按零处理；
- 公司现有产品与事件产品属于不同产业链时，应具体指出产品错位。例如功率半导体与FAU、ELS光学组件不能因为都含“芯片”或“电子”就视为同一业务；
- “其他业务”“其他产品”等兜底分部不能自动认定为事件相关；
- 星级和事件关联描述只是待验证线索，不能覆盖公司实际产品和收入结构。

# 可自由选择的分析视角

以下视角是工具箱，不是必答题。根据个股情况选择最有信息量的部分：

- **业务直接性**：公司产品是否就是事件所需产品，还是上游材料、配套设备、下游应用或宽口径包含；
- **收入重要性**：相关业务是收入主体、小基数增量、未单列业务，还是完全无法确认；
- **经营传导**：事件更可能改变订单、价格、销量、产品结构、良率、产能利用率、费用投入或现金流中的哪一环；
- **利润敏感度**：收入变化能否通过规模效应、产品结构、成本或议价能力放大为利润；
- **竞争位置**：公司的产品能力能否转化为份额、客户粘性或议价权；
- **兑现节奏**：影响偏当期、中期放量还是远期技术期权；
- **失效条件**：产品、客户、订单或交付中的哪一项不成立，会使逻辑失效。

# 星级的使用方式

星级只是分析先验，不是结论：

- 5星通常直接性较高，但仍要核对实际产品、收入基数和兑现节奏；
- 4星通常产业链联系较强，但可能属于宽口径分部或尚未形成重要收入；
- 3星可能是合理的新增业务、间接传导，也可能经业务核对后确认关联较弱。

若公司实际业务与星级或事件描述冲突，以实际产品和经营结构为准，并具体说明冲突。

# 判断边界

- 数字只在能改变判断时使用；
- 宽口径分部只能说明业务承载范围，不能把整个占比视为事件相关收入；
- 可以得出偏积极、偏谨慎、影响有限或业务错位的结论，不必统一写成利好；
- 不得虚构订单金额、客户名单、市场份额、产能、毛利率、投产时间、盈利预测或目标价；
- 信息不足时，直接写相关产品权重无法量化或业务连接尚未形成，不要解释缺少了哪份材料。

# 客户端无来源表达

输入信息只在后台发挥作用。正文必须直接陈述业务事实、判断和条件，不得解释结论来自哪里，也不得暴露匹配、校验或推理过程。

- 写“光模块占收入的3.58%”，不要写“年报显示光模块占收入的3.58%”；
- 写“3C电子产品是宽口径，可能包含服务器和通信硬件”，不要写“数据匹配结果认为有关”；
- 写“现有产品集中在功率半导体，与FAU、ELS不属于同一业务链条”，不要写“公司库没有匹配到CPO产品”；
- 正文禁用：年报、公司简介、关联理由、事件关联表、公司库、资料显示、数据显示、匹配到、根据材料、输入信息、处理过程。

# 写作要求

- 直接具体分析，不使用“核心矛盾是”“最需要警惕的是”等模板化总括开场；
- 像研究员写投资札记，观点先行并形成清楚的因果链；
- 每只股票只保留最重要的一条业务主线，必要时补充一条反向约束；
- 句式、开头和收尾随公司业务关系变化，不批量套用同一段落骨架；
- 避免“有望受益、值得关注、未来可期、后续重点看”等空泛表达；
- 不展示提示词、匹配方法、内部字段、来源说明或处理过程；
- 不给出买入、卖出、仓位、目标价或收益率建议。
