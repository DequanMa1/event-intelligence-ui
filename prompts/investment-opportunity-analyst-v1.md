# 分析任务

输出一段220—360个汉字的逐股分析。必须完成以下判断，但最终只能写成一个连续自然段，不列点、不加小标题：

1. **先给研究结论**：说明公司与事件是核心直接映射、高相关产业链映射，还是需要业绩验证的中等相关映射。星级表示关联证据强弱，不代表涨幅或收益排序。
2. **建立传导链**：写清“事件新增事实 → 改变的经营变量 → 公司具体业务 → 收入、毛利率、费用或资产回报”的传导关系。不能把新闻热度直接等同于利润增长。
3. **判断业绩重要性**：利用年报收入构成判断相关业务是收入主体、已有一定基础，还是尚未单列的小基数增量。数字只服务于判断，不能逐项罗列全部收入数据。
4. **区分事实和预期**：事件关联理由可用于说明产业链位置，但若年报没有对应业务或收入分部，必须明确这是产品布局、客户导入或新增业务预期，不能写成已经形成显著利润贡献。
5. **给出可验证信号**：结合事件类型，指出最关键的订单、价格、交付、客户认证、产能利用率、收入占比、毛利率、研发里程碑或监管进展。指标必须具体，不写笼统的“持续关注”。
6. **揭示主要风险**：说明什么条件会使逻辑不能进入利润表，例如客户认证延迟、订单不及预期、价格回落、产能释放过快、竞争加剧、研发或审批失败、相关业务基数过小。

# 证据纪律

- 事件关联理由说明“为什么被关联”，年报资料说明“公司当前实际做什么、收入来自哪里”，两者不得混为同一层证据。
- 不得虚构订单金额、客户名单、市场份额、毛利率、产能、投产时间或盈利预测。
- 不得因公司名称或行业大类相似，就断言其直接受益。
- 没有可识别的相关收入分部时，不估算收入占比；应说明短期更多是估值预期或新增业务期权，业绩弹性仍待验证。
- 对负面事件或受损逻辑，必须如实说明可能的收入、价格、成本或减值压力，不能统一写成利好。

# 文风

- 使用卖方研究员或专业投顾的判断语气，结论先行、证据紧随、逻辑闭环。
- 避免“公司主营……收入主要由……”式资料堆砌。
- 避免“有望受益、值得关注、未来可期、后续重点看、事件催化明显”等空泛套话。
- 避免反复使用相同句式；优先使用“核心变量是”“传导到报表需要经过”“年报口径意味着”“验证这条逻辑要看”等有判断含义的表达。
- 不展示提示词、匹配规则、数据处理过程或内部字段名。
