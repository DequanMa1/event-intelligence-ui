# 多研报事件演示审阅记录

本记录对应网页演示版本 `multi-report-demo-v3`。筛选条件为：Excel 中同一 `API_main_id` 至少关联 3 篇研报，并且本地至少存在 2 份可通读 PDF。网页中的“01 事件事实”由 API 原始详情的 `sourceReason` 与 `topicPaiPaiInfoDto.answer` 重新转述；“02 相关研究”只引用已匹配并通读的本地 PDF。

## 27308｜英伟达确认 CPO 已在 Spectrum-X 量产

- Excel 关联：13 篇；本地通读：2 篇。
- 直接相关：`3007382067`，华源证券《机械行业周报：重视CPO相关测试、耦合设备，物理AI发展加速》。用于支持 CPO 测试对象扩展、光电联合测试、耦合精度和自动化率等判断。
- 关联不足：`3007407090`，平安证券（香港）《每日晨报》。正文讨论英伟达服务器延期传闻和产品路线图，未讨论 CPO，不作为事件核心证据。

- Excel 关联：9 篇；本地通读：2 篇。

## 证据边界

- “Excel 已关联”仅表示映射存在，不等于研报观点与新闻事件一致。
- 正文未匹配的研报只展示题名、机构、日期和关联排名，不生成观点摘要。
- 报告中的行业数据均以“报告称”“报告列示”表述，不升级为独立核验事实。
